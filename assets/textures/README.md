# Textures

Put texture packs here: Kenney zips as they come (for example `kenney_prototype-textures.zip`), or loose PNG/JPG files.
Say which pack is for what (ground, walls, wood, metal, cloth...) if you have something in mind; otherwise Claude will
pick what fits. Only the textures that get used are copied into the game (`src/`), resized to what they need to be.
